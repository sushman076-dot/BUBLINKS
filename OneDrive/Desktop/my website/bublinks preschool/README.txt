Bublinks Preschool Demo

This project uses the supplied Bublinks logo and hero artwork as local assets.

Files:
- index.html
- about.html
- program.html
- gallary.html
- admission.html
- contact.html
- style.css
- script.js
- assets/bublinks-logo.png
- assets/bublinks-hero.png

To run:
1. Open this folder in VS Code.
2. Open index.html.
3. Use Live Server if installed, or open index.html in a browser.

Important:
Keep the assets folder beside index.html. Do not rename the image files unless you also update the HTML/CSS.
